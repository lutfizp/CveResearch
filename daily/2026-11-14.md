# Daily Log — 2026-11-14

- CVE: CVE-2026-63277 (LibreOffice Calc external data link → RCE)
- Platform: Windows
- Category: rce
- Trigger: file_handler
- Trigger detail: `poc.odt` opened in pinned LibreOffice 26.2.4.2. The Writer document embeds a Calc object whose `calcext:data-mappings` entry uses the SQL provider and names a JDBC driver with a remote `http://127.0.0.1:8099/Evil.jar` classpath. Loading the embedded object fetches the driver and its static initializer runs `cmd.exe /c <command>`. Control: LibreOffice 26.2.5.2, which requires `file:` classpath entries.
- Outcome: Command execution in the LibreOffice process (`whoami` + `CVE_MARKER_63277`; custom `--cmd` also verified).
- Folder: [windows/rce/CVE-2026-63277/](../windows/rce/CVE-2026-63277/)
- Public PoC: yes (Codean Labs PoC for the same mechanism; Linux `/proc/self/fd` self-reference. This lab ports it to Windows with an absolute self-reference and its own driver/ODT/server.)
- Status: pass
- Evidence: [check output](../windows/rce/CVE-2026-63277/evidence/check-output.txt), [check beacon](../windows/rce/CVE-2026-63277/evidence/check-beacon.log), [exploit output](../windows/rce/CVE-2026-63277/evidence/exploit-output.txt), [exploit beacon](../windows/rce/CVE-2026-63277/evidence/exploit-beacon.log), [control beacon (empty)](../windows/rce/CVE-2026-63277/evidence/control-beacon.log), [versions/hashes](../windows/rce/CVE-2026-63277/evidence/versions.txt), [sources](../windows/rce/CVE-2026-63277/notes/SOURCE.md)
