# Daily Log — 2026-11-16

- CVE: CVE-2026-45184 (Kdenlive project file → FFmpeg proxy args → RCE)
- Platform: Linux
- Category: rce
- Trigger: file_handler
- Trigger detail: malicious `cve-2026-45184-*.kdenlive` opened by Kdenlive 26.04.0 (x86_64 AppImage, Ubuntu 24.04 container, Xvfb). The project sets `_replaceproxy=1` and `kdenlive:docproperties.proxyparams`; on open Kdenlive runs FFmpeg with attacker-controlled `-dump_attachment`, `-f concat -safe 0 -protocol_whitelist file,data`, `-skip_initial_bytes`, and `-af ladspa=file=...`, loading a shared library whose constructor runs the command. Control: Kdenlive 26.04.1, which discards the malicious proxyparams.
- Outcome: Command execution in the Kdenlive/FFmpeg process (`id` + `CVE_MARKER_45184`; custom `--cmd` also verified).
- Folder: [linux/rce/CVE-2026-45184/](../linux/rce/CVE-2026-45184/)
- Public PoC: yes (Codean Labs `single_file_rce.kdenlive`). This lab regenerates the payload, replaces `gnome-calculator` with a configurable command, and recomputes the `skip_initial_bytes` offset.
- Status: pass
- Evidence: [check summary](../linux/rce/CVE-2026-45184/evidence/check/summary.txt), [check marker](../linux/rce/CVE-2026-45184/evidence/check/marker.txt), [check screenshot](../linux/rce/CVE-2026-45184/evidence/check/screenshot.png), [exploit summary](../linux/rce/CVE-2026-45184/evidence/exploit/summary.txt), [custom command output](../linux/rce/CVE-2026-45184/evidence/exploit/custom.txt), [exploit screenshot](../linux/rce/CVE-2026-45184/evidence/exploit/screenshot.png), [control summary](../linux/rce/CVE-2026-45184/evidence/control/summary.txt), [control screenshot](../linux/rce/CVE-2026-45184/evidence/control/screenshot.png), [versions/hashes](../linux/rce/CVE-2026-45184/evidence/versions.txt), [sources](../linux/rce/CVE-2026-45184/notes/SOURCE.md)
- Blockers: The AppImage bundles FFmpeg 8.0.1 without the `ladspa` filter, so the lab uses Ubuntu's FFmpeg 6.1.1 (LADSPA present); Kdenlive's vulnerable argument handling is unchanged. The headless startup "Error" dialog is dismissed with `xdotool`. The proxy job reports failure after the constructor has already executed.
