## Kandidat

### CANDIDATE-01 — CVE-2026-15776 (Chromium/V8 RegExp write barrier → renderer RCE)

- **Bug**: `RegExp.prototype[Symbol.matchAll]` + `Symbol.species` menyisipkan HeapNumber `lastIndex` tanpa write barrier → type confusion (CWE-843).
- **Affected**: Chrome/Chromium `< 150.0.7871.125`; CVSS 8.8; crbug `532595489`; fix V8 commit `de11d56041d5aa9c5e69b031990ad17068dbef7a`.
- **Target terpasang**: chromium `148.0.7778.178-1` → affected.
- **Kontrol**: `150.0.7871.181-1` tersedia di repo apt Kali yang sama → bisa dipin tanpa Chrome for Testing.
- **Publik**: writeup lengkap + kode exploit utuh untuk d8 V8 15.2.0 (commit `0c7a9d0d8c05491e8053d7259a1a6b11e75c1907`, `v8_enable_sandbox=false`); primitif `addr_of` / `heap_read` / `heap_write` + spray fake-array sudah jadi. Sumber: `raw.githubusercontent.com/Serotav/Writeups/main/v8/CVE-2026-15776-From-Regex-To-Rce.md`.
- **Effort**: port konstanta alamat (map `PACKED_DOUBLE_ELEMENTS`/`PACKED_ELEMENTS`, offset cage) dari d8 sandbox-off ke Chromium 148 sandbox-on; recalibrate spray.
- **Risiko**: alamat berubah per build; exploit bisa tidak stabil sampai offset dihitung ulang.
- **Kenapa kuat**: satu-satunya kandidat dengan kode exploit publik utuh; target dan kontrol dua-duanya bisa dipin dari apt yang sama; renderer-only sudah diterima preseden `windows/rce/CVE-2026-85046`.

### CANDIDATE-02 — CVE-2026-125742 (7-Zip CAB/LZX window desync → heap OOB write → RCE)

- **Bug**: jalur continuation CAB hanya me-reset `_pos` kalau tepat sama dengan `_winSize`; volume lanjutan dengan window lebih kecil menyisakan `_pos` basi → cek `outSize > _winSize - _pos` wrap → tulis OOB ~1.3 MB (CWE-787).
- **Affected**: 7-Zip `< 26.06`; CVSS 8.5; fix commit `d3296e39e1f1f92c7b41c0c3848e65640428d42d`.
- **Target terpasang**: 7zip `26.01+dfsg-2` → affected.
- **Kontrol**: tarball statis resmi `26.06` dari 7-zip.org (apt Kali cuma sampai `26.02`, yang **tidak** memperbaiki CVE ini).
- **Publik**: writeup rinci (root cause, heap grooming, `_IO_file_jumps + 0x20`, House of Apple 2, byte ASLR brute-force 8 varian) tapi **tanpa kode**; penulis melaporkan 19/64 (~30%) sukses dengan ASLR aktif.
- **Effort**: bangun generator CAB 2-volume + encoder LZX sendiri; kalibrasi glibc/build Kali. Tinggi.
- **Risiko**: tertinggi dari tiga; butuh reimplementasi penuh dan tuning alamat.

### CANDIDATE-03 — CVE-2026-125350 (Chromium bundled libxslt `xsl:number` UAF, KEV 2026-11-10)

- **Bug**: `xsltTestCompMatchDirect` di `pattern.c` — reentrancy predicate `count` pada `xsl:number` → double-free/UAF.
- **Affected**: Chrome/Chromium `< 157.0.8103.50`; fix CL `61cab3f7`, cherry-pick `049750111b1e`; masuk CISA KEV 2026-11-10.
- **Target terpasang**: chromium `148.0.7778.178-1` → affected.
- **Publik**: PoC crash nyata + aset regression test upstream (`github.com/TJT001/CVE-2026-125350-PoC`) — crash-only.
- **Kontrol**: **tidak tersedia** — butuh ≥ `157.0.8103.50`; apt Kali hanya `150.0.7871.181-1`, dan CfT tidak punya `linux64` untuk `157.0.8103.50`.
- **Effort**: weaponize UAF dari crash jadi RCE penuh. Tinggi, dan tanpa build kontrol pembuktian "fixed tidak trigger" tidak bisa dilakukan.
