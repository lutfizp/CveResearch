# Daily Log — 2026-11-19

- CVE: CVE-2025-4664 (Chrome Loader Link-header preload referrer-policy bypass → session token / PII leak)
- Platform: Windows
- Category: info_leak
- Trigger: browser_application
- Trigger detail: Chrome for Testing 136.0.7103.92 (win64, `--headless=new`) opens the lab victim app at `http://127.0.0.1:8710/login`; the simulated SSO flow lands on `/profile?session=<JWT>` with synthetic PII, the page embeds `http://127.0.0.1:8712/image`, and that image response sets `Link: <…/log>; rel="preload"; as="image"; referrerpolicy="unsafe-url"`. Chrome sends the full victim URL, including the session JWT, in the `Referer` of the preload. Control: Chrome for Testing 136.0.7103.113, where the preload still fires but sends no `Referer`.
- Outcome: Attacker origin receives the victim profile URL with a valid HS256 session JWT; decoding it yields name, email, phone, address, and the unique marker `CVE_MARKER_4664_<hex>` (12 hex chars per run).
